# 📧 Yahoo Mail Export Endpoint

[← Back to Documentation Index](index.md)

When archiving Yahoo Mail accounts, it's recommended to use Yahoo's dedicated export endpoint for optimal performance and compatibility.

## 🌐 Special Export Endpoint

Yahoo Mail provides a dedicated export IMAP server that is specifically designed for email export operations:

- **Server**: `export.imap.mail.yahoo.com`
- **Port**: `993`
- **Requires SSL**: Yes

Using this export endpoint can help ensure better performance and reliability when archiving large volumes of Yahoo Mail.

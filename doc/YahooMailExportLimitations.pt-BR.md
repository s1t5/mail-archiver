# 📧 Yahoo Mail Export Endpoint {#yahoo-mail-export-endpoint}

[← Voltar para o Índice de Documentação](index.md)

Ao arquivar Contas do Yahoo Mail, recomenda-se usar o endpoint de exportação dedicado do Yahoo para melhor desempenho e compatibilidade.

## 🌐 Special Export Endpoint {#special-export-endpoint}

O Yahoo Mail fornece um servidor IMAP de exportação dedicado que é projetado especificamente para operações de exportação de e-mail:

- **Server**: `export.imap.mail.yahoo.com`
- **Port**: `993`
- **Requires SSL**: Yes

O uso deste endpoint de exportação pode ajudar a garantir melhor desempenho e confiabilidade ao arquivar grandes volumes de Yahoo Mail.

# 📧 Yahoo Mail Export Endpoint {#yahoo-mail-export-endpoint}

[← Назад к индексу документации](index.md)

При архивации учетных записей Yahoo Mail рекомендуется использовать выделенный эндпоинт экспорта Yahoo для обеспечения оптимальной производительности и совместимости.

## 🌐 Специальный эндпоинт экспорта {#special-export-endpoint}

Yahoo Mail предоставляет выделенный IMAP-сервер экспорта, который специально разработан для операций экспорта электронной почты:

- **Server**: `export.imap.mail.yahoo.com`
- **Port**: `993`
- **Requires SSL**: Yes

Использование этого эндпоинта экспорта поможет обеспечить лучшую производительность и надежность при архивации больших объемов Yahoo Mail.

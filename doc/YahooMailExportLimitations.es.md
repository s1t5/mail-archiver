# 📧 Yahoo Mail Export Endpoint {#yahoo-mail-export-endpoint}

[← Volver al Índice de Documentación](index.md)

Al realizar el Archivo de Cuentas de Yahoo Mail, se recomienda utilizar el endpoint de exportación dedicado de Yahoo para obtener un rendimiento y una compatibilidad óptimos.

## 🌐 Special Export Endpoint {#special-export-endpoint}

Yahoo Mail proporciona un servidor IMAP de exportación dedicado que está diseñado específicamente para operaciones de exportación de correo electrónico:

- **Server**: `export.imap.mail.yahoo.com`
- **Port**: `993`
- **Requires SSL**: Sí

El uso de este endpoint de exportación puede ayudar a garantizar un mejor rendimiento y fiabilidad al realizar el Archivo de grandes volúmenes de Yahoo Mail.

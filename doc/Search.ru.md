# 🔍 Mail Search {#mail-search}

[← Back to Documentation Index](index.md)

## 📋 Overview {#overview}

Поиск — это сердце почтового архива. Mail Archiver выполняет полнотекстовый поиск (**full text**)
по вашей архивированной почте — теме, телу письма, отправителю и получателям — по всем
аккаунтам, к которым у вас есть доступ, и возвращает результаты за миллисекунды даже в
архивах с миллионами сообщений.

В этом руководстве рассматриваются интерфейс поиска, синтаксис запросов, фильтры, сортировка,
пагинация, а также действия, которые необходимо предпринять при работе с набором результатов.

> **ℹ️ Поиск видит только то, что видите вы.** Результаты фильтруются в соответствии с
> вашими правами доступа. Пользователь без прав администратора находит только ту почту,
> которая относится к назначенным ему почтовым ящикам — это ограничение применяется непосредственно
> к самому запросу, а не в интерфейсе.

## 🚀 Accessing Search {#accessing-search}

1. Войдите в систему и выберите **Archive** в главном меню
2. Строка поиска находится над списком результатов

При открытии архива без поискового запроса отображаются ваши последние письма, начиная с самых новых.
Вы можете просматривать их оттуда или сузить поиск с помощью фильтров.

## 🎯 The Search Interface {#the-search-interface}

| Field | What it does |
|---|---|
| **Search Term** | Полнотекстовый запрос — см. [Query Syntax](#-query-syntax) ниже |
| **From** | Только письма, отправленные в эту дату или позже |
| **To** | Только письма, отправленные в эту дату или раньше |
| **Direction** | `All`, `Incoming` или `Outgoing` |
| **Account** | Ограничить поиск одним почтовым аккаунтом |
| **Folders** | Ограничить поиск одной папкой через дерево папок |
| **Search** | Запустить запрос |
| **Reset** | Сбросить все фильтры |

Поисковый запрос ищет совпадения в **теме, теле письма, отправителе и получателях**
(`From`, `To`, `Cc`, `Bcc`).

### The folder tree {#the-folder-tree}

Папки отображаются в виде **иерархического дерева** слева, дублируя структуру папок
исходного почтового ящика, включая вложенные папки. Нажмите на папку, чтобы ограничить
поиск ею, и используйте элементы управления сворачиванием/разворачиванием, чтобы скрыть дерево,
когда вам нужно больше места на экране.

Выбор папки не меняет ваш поисковый запрос; эти два параметра комбинируются.

## 🧩 Query Syntax {#query-syntax}

Синтаксис намеренно прост. Ниже приведено только то, что приложение
действительно понимает.

### Plain words — and why prefixes work {#plain-words-and-why-prefixes-work}

Введите одно или несколько слов; все они должны присутствовать в результате (поиск с оператором **AND**):

```
invoice january
```

Находит письма, содержащие как `invoice`, так и `january` в поиске по полям.

> **💡 Частичные совпадения слов подбираются автоматически.** Каждое слово рассматривается как
> **префикс**, поэтому поиск по `isenb` также найдет `isenboeck` и `isenböck`, а
> `rech` найдет как `Rechnung`, так и `Rechnungen`. Вам не нужно вводить спецсимвол подстановки —
> его не существует. Это также означает, что очень короткий запрос может
> вернуть слишком много результатов; см. [Performance](#-performance-and-large-archives).

Поиск **нечувствителен к регистру**. `Invoice`, `invoice` и `INVOICE` — это
один и тот же запрос.

### Exact phrases — quotes {#exact-phrases-quotes}

Заключите текст в двойные кавычки, чтобы слова должны были идти **друг за другом** в указанном
порядке:

```
"important meeting"
```

Без кавычек `important meeting` также найдет письмо, где эти два
слова встречаются в разных предложениях. С кавычками совпадет только соседняя фраза.

### Field-specific search {#field-specific-search}

Добавьте имя поля и двоеточие перед термином, чтобы искать **только** в этом поле:

| Syntax | Searches in |
|---|---|
| `subject:invoice` | Только в теме (Subject) |
| `from:john` | Только в отправителе (Sender) |
| `to:example.com` | Только в получателях (Recipients) |
| `body:important` | Только в теле письма (Body) |

Имена полей нечувствительны к регистру (`Subject:` тоже работает), и каждое из них можно
комбинировать с кавычками для поиска фразы:

```
subject:"monthly invoice"
body:"payment terms"
```

> **ℹ️ Поддерживаются четыре поля:** `subject`, `body`, `from`, `to`. Запись
> `cc:someone` или `bcc:someone` **не является** поиском по полю — термин рассматривается
> как обычный текст и ищется по всем полям. Чтобы найти получателя, который
> был только в Cc, ищите адрес или имя без префикса.

### Combining everything {#combining-everything}

Фильтры и термины суммируются. Этот запрос находит письма от любого страховщика,
со фразой "car insurance" в теле письма и словом "invoice" в теме:

```
"car insurance" body:"car insurance" subject:invoice from:insurance
```

Практические комбинации:

```
from:amazon subject:"your order"        # order confirmations from Amazon
to:@example.com body:"contract"          # contracts sent to a domain
"rechnung" from:telekom                  # Telekom invoices
subject:mahnung                          # everything that looks like a reminder
```

### Characters that are ignored {#characters-that-are-ignored}

Парсер запросов удаляет символы `& | ! ( ) : *` из отдельных терминов,
поскольку они имеют значение в базовом движке полнотекстового поиска. Если ваш поиск
не возвращает ожидаемых результатов, проверьте, не является ли причиной специальный символ.

## 📊 Sorting and Paging {#sorting-and-paging}

### Sorting {#sorting}

Нажмите на заголовок столбца, чтобы отсортировать. Сортируемые столбцы:

| Column | Sorts by |
|---|---|
| **Subject** | Тема, по алфавиту |
| **From** | Отправитель |
| **To** | Получатели |
| **Date** | Дата отправки |

Повторное нажатие на тот же заголовок меняет направление сортировки. По умолчанию — **сначала новые**.

### Page size {#page-size}

Выберите количество результатов на одной странице:

**20** (по умолчанию) · **50** · **75** · **100** · **150**

Большая страница показывает больше контекста, но дольше отрисовывается. Используйте
управление **Previous** / **Next**, чтобы перемещаться по страницам результатов;
счетчик результатов покажет, сколько всего писем найдено.

> **ℹ️ Ваш часовой пояс применяется к отображаемым датам.** Отображаемое время
> конвертируется из UTC в ваш настроенный часовой пояс, поэтому дата, которую вы видите, соответствует
> вашему местному календарю — это полезно при поиске в районе полуночи.

## 👁️ Working with Results {#working-with-results}

В каждой строке отображаются аккаунт, отправитель, тема, дата и **📎 иконка скрепки**,
если к письму есть вложения. Скрепка — это только индикатор, а не фильтр.

Нажмите **Details**, чтобы открыть письмо:

- Полное тело письма (HTML или обычный текст)
- **Attachments**, список с возможностью скачать каждое вложение
- **Download as EML** — полное сообщение для использования в других программах
- **Restore** — копирование письма обратно в активный почтовый ящик

См. [Mailbox Migration](MailboxMigration.md) для восстановления писем в почтовый ящик.

## ✅ Acting on Many Results at Once {#acting-on-many-results-at-once}

Результаты можно выбирать и обрабатывать массово. Включите **Selection Mode**, чтобы появились
чекбоксы, а затем:

- **Select All** / **Deselect All** для текущей страницы
- **Select all {n} matching** — все результаты текущего поиска по всем
  страницам (появляется, когда результатов больше чем на одну страницу)
- **Copy Selected** — восстановить в почтовый ящик
- **Export Selected** — в форматах MBOX или EML
- **Delete Selected** — удалить из архива

Счетчик показывает *"{selected} из {total} выбрано"* во время работы.

### The selection limit {#the-selection-limit}

> **⚠️ Максимум 250 писем можно выбрать за один раз** (настраивается через
> `Selection:MaxSelectableEmails`). При превышении интерфейс покажет *"Maximum
> selections reached (250)"* и **Too Many — Split Required**.

Это ограничение существует потому, что каждая операция должна удерживать затронутые сообщения.
Подсказка *"Split larger operations into multiple batches"* является рекомендуемым
решением: обрабатывайте результаты группами по 250 или менее писем.

**Select all {n} matching** также соблюдает это ограничение. Если поиск находит
больше писем, чем позволяет лимит, выбираются первые письма в текущем порядке сортировки
и выводится уведомление *"Maximum selections reached"*. Сузьте поиск (диапазон дат,
папка, аккаунт), чтобы найти остальные.

При попытке превысить лимит появится сообщение: *"Too many emails selected. Maximum allowed is
250 emails. Please reduce your selection or split into multiple operations."*

### Deleting every match of a filter {#deleting-every-match-of-a-filter}

Кнопка **Delete all matches** рядом с *Reset* удаляет каждое письмо,
которое соответствует текущему поиску, а не только текущую страницу или выборку. Она
доступна администраторам и самообслуживающим пользователям и выполняется как фоновая задача,
поэтому лимит в 250 писем на нее не распространяется.

В диалоговом окне подтверждения показано, сколько писем можно удалить и сколько заблокировано
политикой хранения данных. Вам нужно ввести это число, чтобы активировать подтверждение.
Сервер пересчитывает данные еще раз и прерывает операцию, если набор результатов изменился
за это время (например, из-за синхронизации, добавившей почту).

Заблокированные письма никогда не удаляются этой операцией; в статусе задачи они
помечаются как пропущенные. `DeletionPolicy:MaxBulkDeleteEmails` (по умолчанию 100 000) ограничивает количество писем
на одну задачу. Если фильтр находит больше писем, задача отклоняется с просьбой сузить поиск.

Задача появляется на странице [Background Jobs](BackgroundJobs.md), и ее можно там отменить.

### Direct processing vs. background job {#direct-processing-vs-background-job}

Для операций **Copy** и **Export** вы выбираете способ выполнения:

| Option | Behaviour |
|---|---|
| **Process on this page (wait for completion)** | Браузер ожидает завершения; подходит для нескольких писем |
| **Process in background (monitor separately)** | Выполняется как задача; вы можете закрыть браузер |

Экспорт всегда выполняется в фоновом режиме:

> *"The export will run in the background and you will be able to download the
> result from the Jobs page once completed."*

Найти запущенные и завершенные задачи можно на странице [Background Jobs](BackgroundJobs.md).

> **⚠️ Удаление необратимо.** Подтверждение явно сформулировано: *"Are you sure you
> want to permanently delete {n} selected email(s)? This action cannot be undone
> and each deletion will be logged for audit purposes."* Удаления записываются
> в лог доступа.

## ⚡ Performance and Large Archives {#performance-and-large-archives}

Поиск работает на базе полнотекстового индекса PostgreSQL, поэтому разница между
быстрым и медленным поиском обычно заключается в том, насколько **избирательным**
является запрос.

**Рекомендуется:**

- Добавлять **диапазон дат**, если вы примерно знаете, когда пришло письмо — это
  самый эффективный способ сузить поиск
- Ограничивать поиск **аккаунтом** или **папкой**, если вы знаете, где лежит почта
- Использовать **несколько слов** вместо одного очень короткого
- Использовать поиск по полям (`subject:`, `from:`), чтобы отсечь нерелевантные совпадения

**Следует избегать:**

- Одного короткого префикса, такого как `re` — как поиск по префиксу он охватывает
  огромную часть вашего архива
- Очень широких диапазонов дат в сочетании с распространенным словом
- Пролистывания множества страниц вместо того, чтобы сузить поиск

> **💡 Если поиск кажется медленным, решение обычно в диапазоне дат.** Ограничение
> поиска одним месяцем часто превращает многосекундный поиск в мгновенный, так как
> индекс может пропустить большую часть архива.

## ❓ Troubleshooting {#troubleshooting}

| Symptom | Cause | What to do |
|---|---|---|
| Нет результатов, хотя они ожидались | Слишком специфичный поисковый запрос или опечатка | Попробуйте меньше слов; проверьте орфографию |
| `cc:name` ничего не находит | `cc` не является поддерживаемым полем | Ищите имя без префикса |
| Спецсимвол ломает запрос | `& \| ! ( ) : *` удаляются | Удалите или замените символ |
| Слишком много результатов | Распространенное слово или короткий префикс | Добавьте диапазон дат или поиск по полю |
| *"Too Many — Split Required"* | Выбрано более 250 писем | Уменьшите выборку или разделите операцию |
| Экспорт отсутствует | Он выполняется как фоновая задача | Проверьте [Background Jobs](BackgroundJobs.md) |
| Результаты кажутся неполными | Права доступа к аккаунту | Убедитесь, что почтовый ящик назначен вашему пользователю |
| Даты отображаются неверно | Конвертация часового пояса | Проверьте настройки часового пояса |

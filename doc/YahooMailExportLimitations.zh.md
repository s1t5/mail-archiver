# 📧 Yahoo Mail Export Endpoint {#yahoo-mail-export-endpoint}

[← 返回文档索引](index.md)

在归档 Yahoo Mail 账户时，建议使用 Yahoo 专用的导出端点，以获得最佳性能和兼容性。

## 🌐 特殊导出端点 {#special-export-endpoint}

Yahoo Mail 提供了一个专门为电子邮件导出操作设计的专用导出 IMAP 服务器：

- **Server**: `export.imap.mail.yahoo.com`
- **Port**: `993`
- **Requires SSL**: 是

使用此导出端点可以确保在归档大量 Yahoo Mail 数据时具有更好的性能和可靠性。

# 📤 メールアカウントのエクスポート (EML / MBox) {#exporting-a-mail-account-eml-mbox}

[← ドキュメントインデックスに戻る](index.md)

## 📋 概要 {#overview}

アカウントのエクスポートは、**1つのアカウントのすべてのメッセージ**をダウンロード可能なZIPファイルとして書き出します。これは[ウェブインポート](Import-EML-MBox.md)の対になる機能です。あらゆるメールクライアントや移行ツールで読み取り可能な、アカウントのポータブルなアーカイブを取得できます。

2つのフォーマットが用意されています：

| フォーマット | 内容 | 主な用途 |
|--------|--------------|-------------|
| **EML** | フォルダごとに整理された個別の `.eml` ファイル | メールクライアントへの再インポート、メッセージごとの処理、長期的な可読性 |
| **MBox** | 従来のメールボックスファイル — **フォルダごとに1ファイル** | MBoxを読み取るツールやクライアント、一括テキスト処理 |

どちらの場合も、メッセージは生のRFC-822メッセージとして書き出されるため、**添付ファイルもエクスポートに含まれます**。

> 💡 **ヒント**: アカウント全体ではなく、選択したメッセージのみをエクスポートするには、[Mail search](Search.md#-acting-on-many-results-at-once)のバルクアクションを使用してください。

## 🧭 アクセス方法 {#access}

1. メインメニューから **Mail Accounts** を開きます。
2. アカウント行の **⋮** (その他のアクション) ボタンをクリックし、**Export** を選択します。同じ項目はアカウントの **Details** ページにもあります。

エクスポートには **admin** または **self manager** ロールが必要です。標準ユーザーには項目が表示されますが、使用することはできません。エクスポートは常にアカウント全体を対象とし、日付やフォルダによるフィルタリングはできません。

## 🖥️ エクスポートページの使用方法 {#using-the-export-page}

ページにはアカウントの**合計**、**受信**、**送信**メッセージ数が表示されるため、開始前にジョブの規模を確認できます。その後：

1. フォーマット（**EML** または **MBox**）を選択します。
2. **Start Export** を押します。

エクスポートは**バックグラウンド**で実行されます。ジョブID、選択したフォーマット、タイムスタンプ、および処理済み/合計メッセージ数が表示されるステータスページに移動します。

### ジョブのステータス {#job-statuses}

`Queued` → `Running` → `Completed` / `Failed` / `Cancelled` → `Downloaded`

ジョブが **Completed** に達すると、ステータスページに**ダウンロードボタン**が表示されます。同じジョブは [Jobs](BackgroundJobs.md) ページにもリストされます。

> ⚠️ **エクスポートファイルは自動的にクリーンアップされます。** ZIPファイルは、**ダウンロード成功後**、およびいかなる場合においても**7日後**に削除されます。ファイルが提供されているうちにダウンロードしてください。アーカイブ自体には影響を与えないため、後で新しいエクスポートを簡単に開始できます。

## ⚠️ 注意事項 {#things-to-watch-out-for}

- **大規模なアカウントには時間がかかります。** メッセージ量や添付ファイルによっては、大きなメールボックスの処理に数分かかる場合があり、ZIPファイルが非常に大きくなる可能性があります。ジョブはバックグラウンドで実行されるため、ブラウザを閉じて後でステータスページに戻ってくることができます。
- **サーバーのディスク容量。** ZIPファイルはダウンロード前にサーバー上で組み立てられるため、アーカイブ用に十分な空き容量があることを確認してください。
- **"Export file not found"** — ジョブがまだ完了していないか、ファイルがすでにダウンロードされたか、あるいは7日間のクリーンアップによって削除されました。新しいエクスポートを開始してください。
- **フィルタオプションはありません** — エクスポートはアカウントごとに「すべてか無か」となります。一部のメッセージのみが必要な場合は、検索ページのエクスポートを使用してください。
- **コンプライアンス用のエクスポートではありません。** インデックスファイルを含む監査対応のデータメディア受け渡しには、代わりに [Audit Data Export](AuditExport.md) を使用してください。これは、監査ツールが期待する表形式のマスデータフォーマットのパッケージを生成します。

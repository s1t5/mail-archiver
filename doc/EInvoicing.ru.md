# Предварительный просмотр счетов XRechnung {#xrechnung-invoice-preview}

Mail-Archiver распознает XML-вложения XRechnung и отображает их в виде читаемого PDF формата A4 непосредственно в окне предварительного просмотра вложения. PDF генерируется по запросу и не сохраняется в архиве.

## Что распознается {#what-is-recognised}

- UBL `Invoice` и `CreditNote`, чей `CustomizationID` содержит `xrechnung`.
- CII `CrossIndustryInvoice`, чей
  `GuidelineSpecifiedDocumentContextParameter` содержит `xrechnung`.
- Как счета, так и кредит-ноты.

Рендерится только XRechnung. Документы Peppol BIS, обычные EN 16931 и PDF ZUGFeRD/Factur-X не затрагиваются; их XML отображается как и прежде.

## Где найти {#where-to-find-it}

1. Откройте электронное письмо с XML-вложением XRechnung. В списке вложений отображается значок
   **XRechnung**.
2. Нажмите на вложение. Модальное окно предварительного просмотра отображает сгенерированный PDF в режиме inline.
3. **Download PDF** сохраняет сгенерированный PDF. **Download original XML** сохраняет
   архивированное вложение.
4. Тот же PDF доступен через REST API.

PDF является внутренним вспомогательным средством для чтения, а не юридически значимым оригиналом.
Переданный XML-файл остается приоритетным.

## REST API {#rest-api}

```
GET /api/v1/emails/{id}/attachments/{attachmentId}/invoice-pdf
```

Эндпоинт использует ту же аутентификацию и область видимости аккаунта, что и другие
[эндпоинты вложений](API.md#download-attachment). Он доступен только тогда, когда включен `Api:AllowAttachmentDownloads`.
Для вложения, не являющегося XRechnung, возвращается `404`.

```bash
curl -H "Authorization: Bearer <api-key>" \
     -o rechnung.pdf \
     "https://archive.example.org/api/v1/emails/123/attachments/456/invoice-pdf"
```

## Ограничения {#limits}

- Учитываются только XML-вложения размером до 5 MiB.
- Рендерится не более 1000 строк счета. Если в счете больше строк, в PDF
  указывается, сколько строк присутствуют только в XML.
- PDF генерируется на каждый запрос. Кэширование и фоновые задачи отсутствуют.

## Без валидации {#no-validation}

Предварительный просмотр не проверяет счет на соответствие XRechnung, EN 16931 или любому
другому набору правил. Он только извлекает поля, которые отображает. Некорректный или
неполный XML-файл, который все еще содержит идентификатор XRechnung, может создать
неполный PDF или не создать PDF вовсе. Используйте специализированный валидатор, если вам
требуется подтверждение соответствия.

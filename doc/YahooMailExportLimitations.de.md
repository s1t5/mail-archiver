# 📧 Yahoo Mail Export Endpoint {#yahoo-mail-export-endpoint}

[← Zurück zum Dokumentationsindex](index.md)

Beim Archivieren von Yahoo Mail Konten wird empfohlen, den speziellen Export-Endpoint von Yahoo zu verwenden, um eine optimale Leistung und Kompatibilität zu gewährleisten.

## 🌐 Spezieller Export-Endpunkt {#special-export-endpoint}

Yahoo Mail stellt einen dedizierten Export-IMAP-Server bereit, der speziell für E-Mail-Exportvorgänge entwickelt wurde:

- **Server**: `export.imap.mail.yahoo.com`
- **Port**: `993`
- **Erfordert SSL**: Ja

Die Verwendung dieses Export-Endpunkts kann dazu beitragen, eine bessere Leistung und Zuverlässigkeit beim Archivieren großer Mengen an Yahoo Mail zu gewährleisten.

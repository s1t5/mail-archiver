# 📥 Mailbox Migration Guide {#mailbox-migration-guide}

[← Back to Documentation Index](index.md)

В данном руководстве объясняется, как перенести почтовый ящик от одного поставщика услуг электронной почты к другому с помощью приложения Mail Archiver.

## 📋 Overview {#overview}

Приложение Mail Archiver предоставляет функциональность для миграции электронных писем из исходного почтового ящика в целевой. Это особенно полезно при смене провайдера электронной почты с сохранением истории переписки. Структура папок исходного почтового ящика также сохраняется во время миграции.

> **Перенос только последних писем?** Описанный ниже процесс копирует *весь* архивированный почтовый ящик, и его повторный запуск приведет к дублированию всех данных. Если в новом почтовом ящике должны находиться только письма новее определенной даты, в то время как полная история остается в архиве, используйте [date-windowed offload](Offload.md). Этот метод использует временное окно, позволяет исключать и переименовывать папки, предлагает режим пробного запуска (dry run) и безопасен для повторного использования, так как пропускает то, что уже есть в целевом ящике. Его также можно запускать из командной строки, что позволяет автоматизировать работу с целым парком почтовых ящиков.

## 🚀 Migration Process {#migration-process}

Выполните следующие шаги для миграции вашего почтового ящика:

1. **Add the source account**
   - Перейдите в раздел "Email Accounts"
   - Нажмите "Add Account"
   - Введите данные и учетные данные вашего исходного аккаунта
   - Сохраните аккаунт

2. **Synchronize the source account**
   - Позвольте приложению синхронизировать все письма из исходного аккаунта
   - Дождитесь завершения процесса синхронизации

3. **Add the target account**
   - В разделе "Email Accounts" нажмите "Add Account"
   - Введите данные и учетные данные вашего целевого аккаунта
   - Сохраните аккаунт

4. **Synchronize the target account**
   - Если целевой аккаунт новый, синхронизируйте его, чтобы убедиться в его правильной настройке
   - Дождитесь завершения процесса синхронизации

5. **Initiate the migration**
   - В разделе "Email Accounts" найдите исходный аккаунт
   - Перейдите к деталям аккаунта
   - Выберите опцию "Copy All Emails to Another Mailbox"
   - Выберите целевой аккаунт и целевую папку
   - Включите опцию **"Preserve Folder Structure"** — в этом случае выбранная целевая папка будет служить корнем, под которым будет рекурсивно воссоздана вся структура папок источника
   - Если эта опция не включена, все письма будут помещены непосредственно в выбранную целевую папку (плоским списком, без подпапок)
   - Запустите процесс миграции

6. **Monitor the migration**
   - Если количество писем велико, миграция будет выполняться как фоновая задача
   - Статус и прогресс миграции можно просмотреть на вкладке "Jobs"
   - Дождитесь успешного завершения миграции

7. **Disable the source account**
   - После успешного переноса вернитесь к исходному аккаунту
   - Установите статус исходного аккаунта "Disabled" в настройках аккаунта
   - Это гарантирует, что он больше не будет архивироваться в будущем

## ⚠️ Important Notes {#important-notes}

- Этот процесс не является повторяемым: его повторный запуск добавит каждое сообщение еще раз. [date-windowed offload](Offload.md) является подходящей альтернативой для повторных операций.
- Убедитесь, что исходный аккаунт имеет достаточные права для чтения всех писем
- Убедитесь, что в целевом аккаунте достаточно места для переносимых писем
- Процесс миграции может занять некоторое время в зависимости от количества писем и скорости соединения
- Рекомендуется выполнять миграцию в часы минимальной нагрузки, чтобы минимизировать влияние на почтовый сервис
- Регулярно проверяйте статус миграции на вкладке "Jobs", чтобы убедиться в ходе процесса
- После миграции проверьте, что все письма были успешно перенесены в целевой аккаунт

## ✅ Best Practices {#best-practices}

- Всегда тестируйте процесс миграции на небольшом подмножестве писем перед переносом всего почтового ящика
- Сделайте резервную копию важных писем перед началом миграции
- Запланируйте миграцию на время минимального использования электронной почты
- Внимательно следите за прогрессом миграции и будьте готовы устранить любые возникающие проблемы
- После завершения миграции убедитесь, что все письма перенесены правильно и доступны для использования

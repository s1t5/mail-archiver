# 📧 Yahoo Mail Export Endpoint {#yahoo-mail-export-endpoint}

[← Vissza a dokumentáció indexéhez](index.md)

A Yahoo Mail fiókok archiválásakor javasolt a Yahoo dedikált export endpointjának használata az optimális teljesítmény és kompatibilitás érdekében.

## 🌐 Speciális Export Endpoint {#special-export-endpoint}

A Yahoo Mail egy dedikált export IMAP szervert biztosít, amely kifejezetten az e-mail export műveletekre készült:

- **Server**: `export.imap.mail.yahoo.com`
- **Port**: `993`
- **Requires SSL**: Igen

Ezen a export endpointon keresztül történő használat jobb teljesítményt és megbízhatóságot biztosíthat a nagy mennyiségű Yahoo Mail archiválása során.

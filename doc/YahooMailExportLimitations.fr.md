# 📧 Yahoo Mail Export Endpoint {#yahoo-mail-export-endpoint}

[← Retour à l'index de la documentation](index.md)

Lors de l'archivage de comptes Yahoo Mail, il est recommandé d'utiliser le point de terminaison d'exportation dédié de Yahoo pour une performance et une compatibilité optimales.

## 🌐 Point de terminaison d'exportation spécial {#special-export-endpoint}

Yahoo Mail fournit un serveur IMAP d'exportation dédié qui est spécifiquement conçu pour les opérations d'exportation d'e-mails :

- **Server** : `export.imap.mail.yahoo.com`
- **Port** : `993`
- **Requires SSL** : Yes

L'utilisation de ce point de terminaison d'exportation peut aider à garantir de meilleures performances et une meilleure fiabilité lors de l'archivage de volumes importants de Yahoo Mail.

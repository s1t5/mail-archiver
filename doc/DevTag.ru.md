# 🧪 Использование ознакомительных версий (Dev Tag) {#using-development-versions-dev-tag}

[← Назад к индексу документации](index.md)

## 📋 Обзор {#overview}

В данном руководстве объясняется, как переключиться со стабильной версии `latest` на ознакомительную версию `dev` Mail Archiver для тестирования исправлений ошибок и новых функций. Это особенно полезно для пользователей, которые хотят протестировать исправления до их официального выпуска.

## ⚠️ Важные замечания {#important-considerations}

Перед переключением на ознакомительную версию, пожалуйста, примите во внимание следующее:

- **Ознакомительные версии могут содержать ошибки или нестабильные функции**, которые отсутствуют в стабильном релизе
- **Всегда делайте резервную копию своих данных** перед переключением на ознакомительную версию
- **Используйте ознакомительные версии только для тестирования**, а не в рабочих средах (production)
- **Сообщайте о любых обнаруженных проблемах**, чтобы помочь улучшить программное обеспечение

## 🛑 Остановка контейнера (рекомендуется) {#stopping-the-container-recommended}

Перед переключением на ознакомительную версию рекомендуется остановить контейнер:

```bash
docker compose down
```

## 🔄 Переключение на Dev Tag {#switching-to-the-dev-tag}

1. Откройте ваш файл `docker-compose.yml` в текстовом редакторе

2. Найдите раздел сервиса `mailarchive-app` и измените тег образа с `latest` на `dev`:
```yaml
services:
  mailarchive-app:
    image: s1t5/mailarchiver:dev  # Changed from :latest to :dev
    # ... other configuration remains the same
```

3. Сохраните изменения в вашем файле `docker-compose.yml`

## 📥 Загрузка ознакомительного образа {#pulling-the-development-image}

После обновления файла docker-compose необходимо загрузить ознакомительный образ:

```bash
docker compose pull
```

Эта команда загрузит последнюю ознакомительную версию образа Mail Archiver.

## ▶️ Запуск контейнера с новой версией {#starting-the-container-with-the-new-version}

После загрузки нового образа запустите контейнер, чтобы использовать ознакомительную версию:

```bash
docker compose up -d
```

## 🔁 Возврат к стабильному релизу {#switching-back-to-stable-release}

Если вы хотите вернуться к стабильной версии, выполните следующие шаги:

1. Остановите контейнер:
```bash
docker compose down
```

2. Отредактируйте `docker-compose.yml` и измените образ обратно на:
```yaml
services:
  mailarchive-app:
    image: s1t5/mailarchiver:latest
```

3. Загрузите последний образ:
```bash
docker compose pull
```

4. Запустите контейнер:
```bash
docker compose up -d
```

## 📝 Дополнительные примечания {#additional-notes}

- Ознакомительные версии обновляются чаще, чем стабильные релизы
- Если вы столкнулись с проблемами, проверьте логи на наличие сообщений об ошибках:
  ```bash
  docker compose logs mailarchive-app
  ```
- Вы можете проверить, какая версия запущена в данный момент, просмотрев информацию об образе контейнера:
  ```bash
  docker compose images
  ```

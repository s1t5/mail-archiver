# 📧 Yahoo Mail Export Endpoint {#yahoo-mail-export-endpoint}

[← Documentation Index に戻る](index.md)

Yahoo Mail アカウントをアーカイブする際は、最適なパフォーマンスと互換性を確保するために、Yahoo 専用のエクスポートエンドポイントを使用することをお勧めします。

## 🌐 専用エクスポートエンドポイント {#special-export-endpoint}

Yahoo Mail は、メールのエクスポート操作専用に設計された専用のエクスポート IMAP サーバーを提供しています。

- **Server**: `export.imap.mail.yahoo.com`
- **Port**: `993`
- **Requires SSL**: Yes

このエクスポートエンドポイントを使用することで、大量の Yahoo Mail をアーカイブする際のパフォーマンスと信頼性を向上させることができます。

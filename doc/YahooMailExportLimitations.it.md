# 📧 Yahoo Mail Export Endpoint {#yahoo-mail-export-endpoint}

[← Torna all'indice della documentazione](index.md)

Quando si esegue l'Archivio degli Account Yahoo Mail, si raccomanda di utilizzare l'endpoint di export dedicato di Yahoo per prestazioni e compatibilità ottimali.

## 🌐 Endpoint di Export Speciale {#special-export-endpoint}

Yahoo Mail fornisce un server IMAP di export dedicato, progettato specificamente per le operazioni di export delle email:

- **Server**: `export.imap.mail.yahoo.com`
- **Port**: `993`
- **Requires SSL**: Yes

L'utilizzo di questo endpoint di export può aiutare a garantire prestazioni e affidabilità migliori durante l'Archivio di grandi volumi di Yahoo Mail.

# 🌍 Язык и локализация {#language-and-localization}

[← Назад к индексу документации](index.md)

## 📋 Обзор {#overview}

Интерфейс Mail Archiver доступен на **14 языках**. Выбор языка является
**настройкой конкретного браузера** и хранится в cookie — он не привязан к учетной записи пользователя и никак не влияет на сами архивированные письма: сообщения всегда хранятся именно в том виде, в котором они были получены.

| Язык | Код |
|----------|------|
| English (default) | `en` |
| English (GB) | `en-GB` |
| Slovenščina | `sl` |
| Deutsch | `de` |
| Italiano | `it` |
| Français | `fr` |
| Español | `es` |
| Nederlands | `nl` |
| Русский | `ru` |
| Magyar | `hu` |
| Polski | `pl` |
| Português (Brasil) | `pt-BR` |
| 日本語 | `ja` |
| 简体中文 | `zh` |

**Английский язык является языком по умолчанию и резервным.** Все, что не покрыто переводом, отображается на английском, поэтому частично переведенный язык никогда не оставит вас с пустым ярлыком.

## 🔄 Переключение языка {#switching-the-language}

1. Нажмите на свое **имя пользователя** в правом верхнем углу, чтобы открыть пользовательское меню.
2. В разделе **Language** выберите язык из списка — страница немедленно перезагрузится на выбранном языке.

Выбор записывается в cookie, которые действительны в течение **одного года** и применяются только к этому браузеру. Другие пользователи (или тот же пользователь в другом браузере или на другом устройстве) сохраняют свои собственные настройки. Поскольку срок действия cookie превышает время сессии, выбранный язык сохраняется даже после выхода из системы и повторного входа.

## 🧩 На что влияет (и не влияет) настройка языка {#what-the-language-setting-does-and-does-not-affect}

- **Переведено:** весь текст интерфейса — меню, кнопки, метки форм, сообщения о валидации и ошибках, страницы статуса заданий и описания действий в журнале доступа.
- **Не переведено:** архивированная почта. Тела писем, темы и вложения хранятся и отображаются байт в байт так, как они были получены.
- **Поиск:** синтаксис запросов одинаков для всех языков; см.
  [Mail search](Search.md). Смена языка не меняет способ хранения или индексации почты.
- **Временные метки:** даты отображаются в часовом поясе браузера и форматируются в соответствии с выбранной культурой. Чтобы зафиксировать часовой пояс отображения для всего экземпляра системы, установите `TimeZone__DisplayTimeZoneId` (идентификатор IANA, например,
  `Europe/Berlin`) — см. [Setup and Parameters](Setup.md#-timezone-settings).

## 🛠️ Для контрибьюторов: добавление или изменение переводов {#for-contributors-adding-or-changing-translations}

Переведенные строки находятся в `Resources/`:

| Файл | Назначение |
|------|---------|
| `SharedResource.resx` | Нейтральный файл ресурсов — **English**, 1148 ключей |
| `SharedResource.<culture>.resx` | Один файл на каждый язык, например `SharedResource.de.resx` |

Правила, вытекающие из того, как .NET разрешает ресурсы в данном случае:

1. **Сначала добавляйте новые ключи в нейтральный файл**, а затем в файлы языков. Ключ, отсутствующий в переводе, заменяется английским текстом — ничего не ломается, страница просто остается частично на английском.
2. **Ключ, существующий только в файле перевода, является бесполезным грузом.** Он никогда не будет найден, так как поиск начинается с нейтрального файла. (На момент написания `DeleteAccountAllEmailsButton` и `Sign Out` существуют только в некоторых переводах, а польский файл также содержит оставшиеся ключи дизайнера: `Bitmap1`, `Icon1`, `Name1`.)
3. **`en-GB` по своей конструкции является частичным переопределением.** Он определяет только 245 из 1148 ключей и наследует остальные из нейтрального английского файла — именно поэтому он читается как английский везде, кроме случаев, когда различается британская лексика или форматы дат.
   Китайский (упрощенный), немецкий, испанский, французский, венгерский, итальянский,
   японский, голландский, польский, португальский (Бразилия), русский и словенский
   на данный момент являются полными.
4. **Для добавления целого языка** требуется три вещи: новый
   `SharedResource.<culture>.resx`, запись в списке культур в `Program.cs`
   (`UseRequestLocalization` → `AddSupportedCultures` / `AddSupportedUICultures`),
   и `<option>` в выпадающем списке языков в
   `Views/Shared/_UserInfo.cshtml`. Без последних двух файл никогда не будет использован.

См. [CONTRIBUTING.md](https://github.com/s1t5/mail-archiver/blob/main/CONTRIBUTING.md)
для ознакомления с процессом внесения вклада, стандартами кодирования и тем, как отправить pull request.
